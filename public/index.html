☁️ Cloud Mode Active (GitHub Actions + GitHub Pages 24/7)

This app runs 100% serverless on GitHub Cloud without keeping a local PC on! Background scraping runs automatically on a ~15-minute schedule in GitHub Actions (pushed to the zero-bloat radar-state branch), while search, filtering, and sorting run instantly in your browser.

⚡ Open GitHub Actions (Manual Run / Logs) ↗ 🔐 Configure Telegram / Webhook Secrets ↗ 📝 Edit watchlist.json on GitHub ↗
How to Enable 24/7 Mobile Push Alerts (Telegram / Discord):
1. Create a bot via @BotFather (copy the Token), send /start to your bot in Telegram, then use 🔍 Auto-Detect Chat ID & 🧪 Test Telegram below to verify!
2. Click 🔐 Configure Telegram / Webhook Secrets above → add Repository Secrets TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID (optional: WEBHOOK_URL for Discord).
3. To watch apps 24/7 in the cloud: send /watch AppName to your Telegram Bot, or paste an optional GitHub Personal Access Token below so clicking 🔔 Watch or 🔄 Cloud Sync in this Web UI updates GitHub directly!
Requires repo / contents:write & actions:write scope. Leave blank to keep watchlist rules in this browser or manage cloud rules via Telegram /watch.
