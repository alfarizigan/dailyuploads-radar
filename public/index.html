📜 Riwayat Sinkronisasi

☁️ Mode Cloud Aktif (GitHub Actions + GitHub Pages 24/7)

Aplikasi ini berjalan 100% di Cloud GitHub tanpa perlu menyalakan PC server! Katalog di-update otomatis di background setiap ~15 menit oleh GitHub Actions, sedangkan pencarian/filter/sort di halaman web ini berjalan instan (0 detik).

⚡ Buka GitHub Actions (Sync Manual / Log) ↗ 🔐 Atur Secrets Telegram / Webhook ↗ 📝 Edit watchlist.json di GitHub ↗
Cara Pasang Notifikasi Push Telegram 24/7 di Cloud:
1. Buat bot di @BotFather (salin Token) & dapatkan Chat ID kamu (bisa coba tombol 🧪 Test Kirim Telegram di bawah untuk tes!).
2. Klik 🔐 Atur Secrets Telegram / Webhook di atas → tambahkan Repository Secret TELEGRAM_BOT_TOKEN dan TELEGRAM_CHAT_ID (opsional: WEBHOOK_URL untuk Discord).
3. Untuk menandai aplikasi agar dipantau 24/7 di Cloud: chat /watch NamaAplikasi ke Bot Telegram kamu, atau isi GitHub Token opsional di bawah agar tombol 🔔 Watch di Web ini langsung tersinkron ke Cloud!
Jika dikosongkan, tombol 🔔 Watch tetap berfungsi menyimpan di browser ini, dan kamu tetap bisa memakai /watch via Bot Telegram.

⏱️ Auto-Sync & Desktop Notification

Quick sync sangat ringan (~1-2 detik, hanya cek upload terbaru di halaman 1).

✈️ Telegram Bot (Notifikasi + Search Interaktif!)

1. Buat bot di @BotFather lalu salin Token.
2. Aktifkan Interactive Bot di bawah, simpan, lalu kirim /start ke bot kamu untuk mendapatkan Chat ID.
3. Bot bisa dipakai langsung untuk /search, /latest, /watch, /watchlist, /sync!
